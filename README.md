# Bangladesh Real Life Simulator

A new Android-first, photorealistic life-simulation game project for Bangladesh.

> This branch has been reset to a clean game-project foundation. The previous NEXVIO Android assistant source and report are no longer part of the current branch tree. Git history is retained by GitHub; this change does not erase historical commits, the main branch, or other branches.

## Product direction
- Photorealistic, real-world presentation — no cartoon styling or decorative 3D look.
- First playable location: one Bangladeshi village, followed by one town.
- Player creates a personal avatar from a photo they own or have permission to use.
- Everyday activities, social interactions, and funny scene creation.
- Built-in gameplay recording and export for social platforms.

## Technical direction
The first prototype uses Unity as a real-time runtime, with realistic scanned/photo-based environments and motion-captured or licensed human animation. Unity is an implementation tool; the visual target is live-action realism, not stylized 3D art.

## Current milestone
This repository contains the initial technical specification and player/camera controller scripts. It is **not yet a complete Unity project or installable APK**. Realistic environment assets, licensed character assets, avatar reconstruction, Android build settings, and device testing remain to be added.
